# Workshop upgrades and character gear

## Philosophy

Use **several complementary upgrade levers** feeding one forge loop: better production, better conversion, bigger buffers, more frequent forging and companion bonuses. Avoid making six systems with separate currencies or redundant stat names. Physical upgrades should visibly transform the player's plot.

## Machines — PLANNED categories, effects to balance

| Station | Job | Primary upgrade dimensions | Status |
|---|---|---|---|
| Extractor / Mine | Generates selected unlocked ore | Ore unlock tier, output rate, efficiency | Core |
| Smelter / Refinery | Converts ore to forging-ready material | Processing rate, yield | Core |
| Material Storage | Buffers materials and optional offline gains | Capacity / offline cap | Core |
| Furnace | Prepares blank for forging | Heat/prep time, material capability | Core |
| Anvil | Where clicks/forging occur | Strike presentation, cycle efficiency, minigame ergonomics | Core |
| Quench Station | Finishes/reveals creation | Finish time and spectacle | **Optional**: combine with furnace/anvil if unnecessary |

The initial six categories came from discussion; whether quench requires its own upgrade ladder remains an open simplification decision.

**Premium models** can visually replace/overlay normal machines and improve throughput/time, but must not give exclusive access to material tiers or randomness categories.

## Player gear — PLANNED

- **Hammer:** visible equipped object; forging efficiency, interaction responsiveness, perhaps a more forgiving high-luck minigame; not an unbounded multiplier to sell value.
- **Gloves:** consistent striking/efficiency and perhaps reduced material waste.
- **Blacksmith apron:** resource consumption/utilities and visual status.

Proposed appearance ladder: wooden/steel/enchanted/legendary hammers; leather/reinforced/runic gloves; basic/armored/master aprons. These are **visual examples**, not fixed product IDs or guaranteed bonus values.

**Hard limit:** manual luck max stays 5x regardless of hammer/gear tier. Do not let a late-game stat silently break the announced multiplier ceilings.

## Workshop look and progression

Players should physically see more elaborate machines, richer furnace fire, more dramatic material colors, distinctive pets and trophy weapons. A strong player's plot should be visually aspirational and compelling to visit. Use shared models plus skins/particles/attachments unless a signature premium product justifies a special mesh.

## Proposed premium examples (unpriced)

- Titan Excavator: exceptional mining machine model, e.g., roughly 2x output.
- Dragon Furnace: dramatic alternate furnace with faster heating and/or throughput.
- Premium forge automation: 4x luck while unattended (not 5x).
- VIP Workshop: special appearance, comfort and production benefits, but not exclusive ore.

All bonuses and stacking rules require modelling before shipping. See [Monetization](07_MONETIZATION.md).
